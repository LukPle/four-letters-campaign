# Four Letters

**Four Letters - CDTM x LMU Marketing Campaign**
<br>
A marketing landing page for [CDTM](https://www.cdtm.com/), built with Vite, React, TypeScript, and Tailwind CSS
<br><br>

## About

Historically, the share of LMU students per CDTM class has been relatively low. This campaign works against that with a simple yet powerful message. The people featured here were once at LMU, joined CDTM, and now hold inspiring and impactful positions. The campaign is hybrid, with posters on campus, social media, and this landing page.

## Local Development Setup

### Prerequisites

- **Node.js** 22.12 or newer. Version 20.19 or newer also works.
- **Git**

### Installation

1. **Clone the repository**
   ```sh
   git clone https://github.com/LukPle/four-letters-campaign.git
   cd four-letters-campaign
   ```

2. **Install dependencies**
   ```sh
   npm install
   ```

3. **Start the development server**
   ```sh
   npm run dev
   ```

Open http://localhost:5173 with your browser to see the result.

### Scripts

| Command | What it does |
| :--- | :--- |
| `npm run dev` | Start the dev server |
| `npm run build` | Check types and build for production |
| `npm run preview` | Serve the production build locally |
| `npm run lint` | Lint the code |
